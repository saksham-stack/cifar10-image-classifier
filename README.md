# CIFAR-10 Image Classifier

A PyTorch convolutional neural network that trains from scratch on CIFAR-10,
evaluates the test set, and predicts the class of a custom image.

## Setup

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Usage

Run these commands from the project directory:

```powershell
python cifar10_classifier.py train --epochs 5
python cifar10_classifier.py eval
python cifar10_classifier.py predict --image path\to\image.jpg
```

The CIFAR-10 dataset is downloaded automatically into `data/` on the first
training or evaluation run. It is excluded from Git because the download is
too large for GitHub's regular file limit.

## Outputs

- `cifar10_cnn.pth`: saved model weights
- `training_curves.png`: training and test loss/accuracy curves
- `confusion_matrix.png`: test-set confusion matrix
- `prediction.png`: output generated by custom-image prediction

The included checkpoint was evaluated at 61.0% test accuracy after a short
training run. Longer training can improve accuracy.
